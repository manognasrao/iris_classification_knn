# iris_classification_knn
iris flower classification using k nearest neighbour method
We use this model to classify flowers such as Setosa, Versicolor and Virginica
Libraries used are numpy, pandas, matplotlib.pyplot.
The dataset is imported from scikit-learn
The Evaluation metrics used are Accuracy score, Confusion Matrix and Classification Report
The steps used here are:
1)Importing the libraries
2)Loading the dataset
3)Specifying the x and y axis. here the x axis is the data and y axis is sepal length, sepal width, petal length and petal width
4)Creating a dataframe
5)Divide the data for training and testing
6)Fit the data into the model respectively
7)Run the evaluation metrics
8)Get the final prediction
